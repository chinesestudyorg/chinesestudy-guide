# ChineseStudy 用原文、拼音和译文读懂中国经典

[English](README.md) · [简体中文](README.zh-CN.md) · [Español](https://chinesestudy.org/es/)

[ChineseStudy](https://chinesestudy.org/) 是一个中国经典阅读网站。读者可以结合原文、拼音、现代汉语解释、外文译文和注解，逐段阅读诗歌与典籍。先读懂一首诗、一个章节，再慢慢扩大阅读范围。

**[开始中文阅读](https://chinesestudy.org/zh-hans/)** · **[进入英文阅读入口](https://chinesestudy.org/en/)**

也可以先看[经典阅读导读](https://chinesestudyorg.github.io/zh/)，或参考[精选原典与字词工具](https://github.com/chinesestudyorg/awesome-chinese-classics/blob/main/README.zh-CN.md)；[一周阅读练习](guides/one-week-reading-plan.md)提供每天可以完成的小任务。

## 新增阅读路径

主站的中英文书库均列有13部书目。诗歌可从《诗经》305篇、《唐诗三百首》306首或《宋词三百首》310篇中选读；论辩和寓言则有《孟子》260个阅读入口、《庄子》33篇入口。不必按书目顺序读，先找一段想读的原文。[^scope]

- **读论证：**从[《何必曰利》](https://chinesestudy.org/zh-hans/books/mengzi/01-he-bi-yue-li/)开始，辨认梁惠王的问题与孟子的回应，再看[《孟子》阅读练习（英文）](guides/reading-mencius.md)。
- **读寓言：**在[《养生主》](https://chinesestudy.org/zh-hans/books/zhuangzi/03-yang-sheng-zhu/)中找到庖丁的故事，把动作、解释和文惠君的领会分别记下。参见[《庄子》阅读练习（英文）](guides/reading-zhuangzi.md)。

## 第一次阅读可以这样安排

1. 选一首诗或一小段原文，先通读一遍。
2. 用拼音确认不熟悉的字，再读现代汉语译文。
3. 回到原文，看译文解释了哪些词，哪些地方还需要注解。
4. 用自己的话写下这一段的意思，再回读一次。

可以从李白的[《月下独酌》](https://chinesestudy.org/zh-hans/books/tangshi-sanbai/004-yue-xia-du-zhuo/)或[《道德经》第 1 章](https://chinesestudy.org/zh-hans/books/dao-de-jing/01/)开始。诗歌适合练习观察意象，短章适合比较字词与译文；篇幅短也可能需要反复读。

## 从人物进入作品

网站的人物页提供背景、核心主题和原文阅读入口。可以从[孔子](https://chinesestudy.org/zh-hans/figures/kongzi/)、[老子](https://chinesestudy.org/zh-hans/figures/laozi/)、[孙子](https://chinesestudy.org/zh-hans/figures/sunzi/)、[李白](https://chinesestudy.org/zh-hans/figures/li-bai/)、[杜甫](https://chinesestudy.org/zh-hans/figures/du-fu/)或[王维](https://chinesestudy.org/zh-hans/figures/wang-wei/)开始，再沿着链接读到具体篇章。


新增人物入口包括[孟子](https://chinesestudy.org/zh-hans/figures/mengzi/)、[庄子](https://chinesestudy.org/zh-hans/figures/zhuangzi/)，以及[白居易](https://chinesestudy.org/zh-hans/figures/bai-juyi/)、[李商隐](https://chinesestudy.org/zh-hans/figures/li-shangyin/)、[杜牧](https://chinesestudy.org/zh-hans/figures/du-mu/)、[韩愈](https://chinesestudy.org/zh-hans/figures/han-yu/)、[柳宗元](https://chinesestudy.org/zh-hans/figures/liu-zongyuan/)和[王昌龄](https://chinesestudy.org/zh-hans/figures/wang-changling/)。可先看人物背景，再进入具体作品。

## 按自己的节奏阅读

阅读页支持切换拼音与译文、调整字号和行距，以及深色模式。遇到文字或译文问题，可通过页内反馈提交具体位置与说明。

[^scope]: 这些数字统计主站公开目录中的阅读入口，不表示某个校勘本或每段译注已经完整核验。这里的中英文目录页数相同，西语仍为有限试点。音频和编号来源说明仅在部分页面提供。 参见[中文书库](https://chinesestudy.org/zh-hans/)及相应书目目录。

[^surname]: 此处只提供读音练习。姓氏源流叙述需要另查出处，不能据此认定个人家族的世系。参见[原文入口](https://chinesestudy.org/zh-hans/books/baijiaxing/full-text/)。
