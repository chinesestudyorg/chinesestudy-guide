# ChineseStudy 用原文、拼音和译文读懂中国经典

[English](README.md) · [简体中文](README.zh-CN.md) · [Español](https://chinesestudy.org/es/)

[ChineseStudy](https://chinesestudy.org/) 是一个中国经典阅读网站。读者可以结合原文、拼音、现代汉语解释、外文译文和注解，逐段阅读诗歌与典籍。先读懂一首诗、一个章节，再慢慢扩大阅读范围。

**[开始中文阅读](https://chinesestudy.org/zh-hans/)** · **[进入英文阅读入口](https://chinesestudy.org/en/)**

也可以先看[经典阅读导读](https://chinesestudyorg.github.io/zh/)，或参考[精选原典与字词工具](https://github.com/chinesestudyorg/awesome-chinese-classics/blob/main/README.zh-CN.md)；[一周阅读练习](guides/one-week-reading-plan.md)提供每天可以完成的小任务。

| [唐诗三百首](https://chinesestudy.org/zh-hans/books/tangshi-sanbai/) | 先选一首诗，辨认其中的景物、人物和情绪变化。 |
| [道德经](https://chinesestudy.org/zh-hans/books/dao-de-jing/) | 一次读一章，留意关键词和前后句的关系。 |

## 第一次阅读可以这样安排

1. 选一首诗或一小段原文，先通读一遍。
2. 用拼音确认不熟悉的字，再读现代汉语译文。
3. 回到原文，看译文解释了哪些词，哪些地方还需要注解。
4. 用自己的话写下这一段的意思，再回读一次。

可以从李白的[《月下独酌》](https://chinesestudy.org/zh-hans/books/tangshi-sanbai/004-yue-xia-du-zhuo/)或[《道德经》第 1 章](https://chinesestudy.org/zh-hans/books/dao-de-jing/01/)开始。诗歌适合练习观察意象，短章适合比较字词与译文；篇幅短也可能需要反复读。

## 从人物进入作品

网站的人物页提供背景、核心主题和原文阅读入口。可以从[孔子](https://chinesestudy.org/zh-hans/figures/kongzi/)、[老子](https://chinesestudy.org/zh-hans/figures/laozi/)、[孙子](https://chinesestudy.org/zh-hans/figures/sunzi/)、[李白](https://chinesestudy.org/zh-hans/figures/li-bai/)、[杜甫](https://chinesestudy.org/zh-hans/figures/du-fu/)或[王维](https://chinesestudy.org/zh-hans/figures/wang-wei/)开始，再沿着链接读到具体篇章。
